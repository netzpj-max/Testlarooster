# TESTLA ROOSTER

[เล่นเกมบนเว็บ](https://netzpj-max.github.io/Testlarooster/)

เกมขับรถและบินสตันต์ 3D แนวอาร์เคด ล้อบรรยากาศงานโชว์รถด้วยมุกไก่ มี 5 ด่าน คอมโบ ภารกิจ คะแนนสูงสุดส่วนตัว และเสียงสังเคราะห์

เวอร์ชัน 1.1.0: ทางลาด 02 ใช้เส้นโค้งเดียวกันทั้งผิวถนนและการวิ่ง รถเกาะจนกลับหัวเต็มที่แล้วออกจากขอบย้อนมาทางเข้า ก่อนหมุนลงล้อ กล้องหลบขอบทางลาดให้มองเห็นรถ เพิ่มหัวพ่นใต้รถตอนกระโดดและชุดหัวพ่นสวนกันสำหรับ Q/E โดยหัวพ่นติดไปกับการหมุนของตัวรถ

## เปิดเล่น

Windows: ดับเบิลคลิก **START-GAME.cmd** เกมจะเปิดในเบราว์เซอร์ที่ `http://127.0.0.1:4188` เมื่อเลิกเล่นดับเบิลคลิก **STOP-GAME.cmd** เพื่อปิดเซิร์ฟเวอร์

ต้องมี Node.js และ Chrome / Edge / เบราว์เซอร์ที่รองรับ WebGL2 เปิด Hardware Acceleration ไม่ต้องติดตั้งแพ็กเกจเพิ่ม ไม่ต้องล็อกอิน และไม่เรียกบริการภาพหรือข้อมูลภายนอก

อีกวิธี: `npm start` แล้วเปิดที่อยู่ด้านบน การเปิด index.html ตรงด้วย file:// ไม่รองรับ ES modules ตามข้อจำกัดของเบราว์เซอร์

## ควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| W / S | เร่ง / ถอย |
| A / D | เลี้ยว; เมื่อบินใช้หันหัว |
| Ctrl หรือ B + A/D | เบรกมือเพื่อดริฟต์ |
| Shift | บูสต์ / พ่นลมพยุงเมื่อบิน |
| Space | กระโดด |
| ↑ / ↓ เมื่อบิน | เชิด / ก้มหัว |
| Q / E เมื่อบิน | หมุนตามแกนยาว |
| R | กลับจุดเริ่ม เสียเวลา 3 วินาที รักษาคะแนนที่เก็บแล้ว |
| Esc | พัก / เล่นต่อ |
| H | แตรไก่ |

มีปุ่มสัมผัสสำหรับมือถือ (แนะนำแนวนอน) และแมปจอยมาตรฐาน: RT/LT เร่ง/ถอย, สติ๊กซ้ายเลี้ยว, สติ๊กขวาเชิดและหมุน, A บูสต์, B กระโดด, X เบรกมือ ยังไม่ได้ตรวจด้วยจอยจริง

## วิธีเล่นและด่าน

ต้องทำภารกิจและคะแนนให้ครบภายในเวลา คะแนนที่รอเก็บจะเข้าคะแนนจริงเมื่อรถลงล้อหรือวิ่งมั่นคง ชนแล้วเสียเฉพาะคอมโบที่ยังไม่เก็บ ท่าซ้ำในคอมโบได้คะแนนลดลง

1. ออกตัวจนไข่สั่น: ดริฟต์ด้วย Ctrl/B และ A/D แล้วผ่านประตูด้านหน้า
2. ไก่ติดเพดาน: เล็งเข้าทางลาดโค้งด้านซ้าย รถจะดูดเกาะผนังและปล่อยตัว จากนั้นปล่อยปุ่มเพื่อช่วยปรับล้อลงพื้น
3. รูสเตอร์โรล: ใช้ทางลาดด้านขวาข้ามรถบรรทุก กด Q/E ค้างให้ครบหนึ่งรอบแล้วปล่อยเพื่อช่วยลงล้อ
4. ไก่หลุดน่านฟ้า: ใช้ทางลาดกลางผ่านห่วง 3 วงแล้วลงแท่นวงกลม ปล่อย Shift หากบินสูงเกินห่วง
5. งานเปิดตัวที่ไม่มีใครขอ: รวมดริฟต์ ผนัง หมุน ห่วง และลงแท่น คะแนนและภารกิจสะสมได้ระหว่างรอบวิ่ง ใช้ R กลับมาตั้งต้นหลังเก็บคะแนนแล้วได้

## ภาพและเสียง

รถและสนามสร้างจากเรขาคณิตของเกม วัสดุโลหะ แสงเงา สะท้อนจาก environment map, bloom, ควันบูสต์ และรอยยาง เมนูและ UI รองรับภาษาไทย มีตัวเลือกลดการเคลื่อนไหว ปิดเสียง และคุณภาพภาพ Low/High

เป็นเกมต้นแบบที่ขัดเกลาภาพและการเล่นในขอบเขตเว็บ ไม่ใช่ผลงาน AAA จากทีมสตูดิโอ และไม่ได้จำลองสมรรถนะรถจริง ใช้ชื่อ/รถ/เสียงที่สร้างใหม่ ไม่ได้บรรจุวิดีโอหรือภาพ Tesla ลงในเกม

## ตรวจสอบ

- `npm test`: 26 การทดสอบฟิสิกส์ คะแนน การชน เส้นทางเล่นผ่านทั้ง 5 ด่าน ความต่อเนื่องที่ขอบทางลาด และตำแหน่ง/ทิศแรงหมุนของหัวพ่น
- `npm run check`: ตรวจไวยากรณ์ โมดูล และไฟล์ที่จำเป็น
- `node scripts/browser-check.mjs --http`: ตรวจเบราว์เซอร์กับเซิร์ฟเวอร์จริง ติดตั้งเครื่องมือทดสอบด้วย `npm install` และ `npx playwright install chromium` หากมี Chrome ติดตั้งไว้จะใช้ Chrome ได้โดยตรง กำหนด `CHROME_PATH` ได้สำหรับพาธอื่น
- ผลรันล่าสุดและภาพหน้าจออยู่ใน `artifacts/browser-report.json` และ `artifacts/*.png`
- `scripts/wall-check.mjs`: เล่นทดสอบทางลาดกลับหัวด้วยคีย์บอร์ดจากจุดเริ่ม ตรวจไอพ่น Space/Q/E และตรวจกล้องไม่ถูกผิวทางลาดบัง ผลอยู่ใน `artifacts/wall-jets-report.json` ภาพท่าทางหยุดเกมค้างเพื่อเก็บภาพและซ่อนเฉพาะกล่องพักเกมในภาพทดสอบ
- `node scripts/check-selection.mjs URL`: ตรวจการปิดเลือกข้อความด้วยการลากและ Ctrl+A รวมทั้งตรวจ SHA-256 ของไฟล์บนเว็บไซต์จริงว่าตรงกับไฟล์ในเครื่อง

ผลเบราว์เซอร์ตรวจการขับและบินผ่านด่าน 4 จริง การดริฟต์ การพักเกม การตั้งค่าข้ามการโหลดใหม่ และปุ่มมือถือทั้งสองแนว ตรวจแบบ headless จึงไม่ใช่ผล FPS ที่รับรองบนเครื่องหรือมือถือทุกชนิด เสียงสร้างได้ใน Web Audio แต่ยังไม่ได้ประเมินคุณภาพด้วยการฟัง
